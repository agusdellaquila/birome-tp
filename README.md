# Birome

Trabajo práctico de Diseño Web, Escuela Da Vinci 2026. Sitio one-page de Birome, el estudio de Victoria Davide y Agustín Dell’Aquila: servicios, web y contenido.

Sitio publicado: https://birome-tp.netlify.app

- `index.html`: la página
- `css/estilos.css`: todos los estilos
- `img/`: imágenes al tamaño final, íconos de Phosphor (MIT) en `img/iconos/`
- `fuentes/`: Ginka (títulos) e Inter (texto)
